# MUSX-CHIP Specifications

MUSX-CHIP is an audio focused extension of CHIP-8, SuperCHIP V1.0/V1.1, CHIP-8E, and XO-CHIP.  It builds upon the foundation of XO-CHIP and introduce additional capabilities to allow for playing sound effects and music.  It is currently a work in progress.

Current Specification: [0.1](specs/MUSX-CHIP_V0.1.md)
